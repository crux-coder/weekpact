Notifications, a few directions

Today's page gives every notice the same card, so a clap, a crewmate finishing a pact and a nudge all look alike, and a busy day becomes a long stack of identical boxes. Each idea below changes one thing: structure (grouping by day), signal (colour and icon per type), volume (rolling up claps), action (reply from the row), scope (per crew) or story (a timeline). They mix well, so feel free to pick parts from several. Scroll inside each phone.

Where I'd start: 1 + 2 together, the day grouping with the type badges. They fix the "wall of identical cards" problem without changing what a notification is, and need no server work. 3 · Digest is the biggest win if claps are noisy, but rolling up across people and days needs a server change. 4 · Reply in place is the most fun, and "clap back" is a nice loop, but it adds buttons to every row.
