# Crew select — card designs

Six ways to draw the options in the press-and-hold crew switcher. Open `index.html`.
The gesture, the drop animation and the blurred backdrop are identical in all six —
only the look of the options changes. In each mock the first crew is the one you are on
and the middle one is drawn as if a finger were on it.

What is wrong with the version on the phone today: the mint shelf under the current crew
is as heavy as the card it sits under, so it reads as a separate green slab rather than
as "this is the one you're on".

| Design | Idea | Cost |
| --- | --- | --- |
| Soft shelf | Keep the raised shelf, always near-black; a mint dot marks the current crew | Smallest change from today |
| Grouped menu | One frosted panel with hairline dividers and a tick | Looks like a system menu, not like the app |
| Monogram rows | A colour tile per crew, name and member count beside it | Needs a colour per crew, and counts we don't load yet |
| Left rail | Flat cards, a 5px rail down the left edge, mint when current | Quietest; least "3D" |
| Cream stickers | The pact cards' own language: cream fill, black outline, hard shadow | Bright panel over a dark screen |
| Just type | No cards at all — big names, current one white, the rest dimmed | Needs its own shade to stay legible over the page |
